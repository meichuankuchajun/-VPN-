# -VPN-
这个项目用于在 Linux VPS 上一键部署一套可直接使用、可直接分发的代理环境，包含：  * `Xray VMess` * `Xray VLESS Reality` * `Shadowsocks 兼容版`：`aes-256-gcm` * `Shadowsocks 2022`：`2022-blake3-aes-256-gcm` * 轻量级 HTTP 订阅文件服务器 * 两个可直接导入 Clash / Mihomo 的订阅链接  这个项目的目标不是做一个复杂面板，而是提供一套：  * 别人拿到脚本就能直接部署 * 部署完成就能直接拿到订阅链接 * 兼顾旧客户端兼容性和新协议支持 * 支持测试栈隔离和卸载清理
